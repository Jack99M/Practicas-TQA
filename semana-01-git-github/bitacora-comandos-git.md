# 📝 Bitácora de Comandos Git — Práctica Semana 01

Comandos de consola aplicados durante la configuración de los repositorios:

```bash
# 1. Configuración global de identidad
git config --global user.name "Jack99M"
git config --global user.email "maytajuan314@gmail.com"

# 2. Inicialización del repositorio local
git init

# 3. Adición de archivos y seguimiento
git add .

# 4. Creación del commit inicial
git commit -m "feat: commit inicial con estructura de practicas"

# 5. Configuración de rama principal
git branch -M main

# 6. Conexión con el repositorio remoto en GitHub
git remote add origin https://github.com/Jack99M/Practicas-TQA.git

# 7. Publicación del repositorio
git push -u origin main
```
