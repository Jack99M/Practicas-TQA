Repositorio personal/grupal para la organización cronológica y temática de las prácticas, ejercicios de laboratorio, talleres en aula y evidencias de aprendizaje desarrolladas a lo largo del semestre en la materia de Testing y Calidad de Software (TQA).

---

## 🎯 Propósito del Repositorio
- Llevar un registro claro y versionado de las prácticas asignadas semana a semana.
- Facilitar la revisión y retroalimentación continua por parte del docente.
- Mantener centralizadas las guías, ejercicios resueltos y código fuente de apoyo.
